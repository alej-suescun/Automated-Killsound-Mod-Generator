# Automated Killsound Mod Generator
Automated Killsound Mod Generator allows you generate a folder ready to copy and paste in your Team Fortress 2 custom folder, with the feature for automated generate the soundscripts for multiple killsounds!

## Installation & Usage
Download the .jar from the [releases](https://github.com/alej-suescun/Automated-Killsound-Mod-Generator/releases) page
